# Icon Catalog

Bundled icons are drawn as native, recolorable PowerPoint shapes (not
images): they take the template's accent color and stay editable. Use them
in `icon_grid` items and `cards` (`"icon": "..."`).

Name an icon by its **Phosphor name** below, or by a **concept alias** in
English or Korean (e.g. `"보안"` → `shield-check`). Unknown names render a
number badge instead and the validator suggests close matches.

Pick the drawable object, not the abstract idea: `lightbulb` for an idea,
`coins` for cost, `users-three` for a team. Use one icon per item, and only
where the icon adds recognition — a deck where every slide has icons reads
as decoration.

Source: [Phosphor Icons](https://phosphoricons.com) (fill weight), MIT
License — `assets/icons/LICENSE-phosphor.txt`. To change the set, edit
`CURATED` in `scripts/build_icon_set.py` and rebuild.
